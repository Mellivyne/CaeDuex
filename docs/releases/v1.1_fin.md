# CaeDuex v1.1_fin

CaeDuex is the new name of Cheat Program. The control panel, opening animation, HUD, mod metadata, and download filenames use the new name. The current feature labels and descriptions are used where they describe the same behavior.

This release carries forward the feature set of v1.2_fix. It includes ten Fabric builds, two Forge builds, and two NeoForge builds.

| Loader | Minecraft versions |
| --- | --- |
| Fabric | 1.20.1, 1.20.4, 1.21.4, 1.21.10, 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, 26.3 |
| Forge | 1.20.1, 1.20.4 |
| NeoForge | 1.21.1 (21.1.266), 26.3 (26.3.0.102) |

Choose the JAR that matches both Minecraft and your loader. Use Java 21 or newer for Minecraft 1.20 and 1.21, and Java 25 or newer for Minecraft 26. Install one CaeDuex JAR per instance. Existing profiles use the same mod ID and configuration directory. SHA256SUMS.txt lists the checksum for each download.
