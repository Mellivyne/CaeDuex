# Cheat Program v1.2_fix

This corrective release fixes the reproduced scrolling crash and improves font-state recovery across supported builds. It also updates shared-projection quality choices. Existing v1.2 and earlier releases remain available unchanged.

## Fixes

- **UI scrolling crash:** completely invisible nested clips no longer submit native text or material draws with zero width/height. The shipped v1.2 failure was reproduced on Minecraft 26.3 with native-font fallback: `Scissor size must be >0, was 100x0`.
- **Safe clipping across versions:** canvas and native-material scissors are bounded to the destination dimensions. Partial/offscreen widgets, nested clips, fractional scales, invalid dimensions and arithmetic overflow are handled consistently.
- **Font-state recovery:** if native glyph drawing throws, the text matrix is restored in a `finally` block. Subsequent interface rendering keeps its original position and scale.
- **Native-font submission:** reuse the existing scissor snapshot instead of querying the same OpenGL state twice per call.

## Shared-projection quality

- New and reset sharing configurations default to **Source quality and frame rate**. Existing saved choices are preserved.
- Select **Source**, **1080p60** or **1080p120**. Both 1080p modes preserve the source aspect ratio. Capture requests, publication pacing and encoding use the chosen target together.
- Publication pacing retains fractional frame timing, avoiding repeated under-rate drops when capture timestamps arrive slightly before a fixed interval.
- Native shared floating lyrics retain their original text/3D rendering and have no video-quality selector.

Source mode uses high-quality compression, without a deliberate resolution or frame-rate cap. It is not a mathematically lossless or zero-latency guarantee. Actual 60/120 FPS depends on the source application, both devices and the network. Video sharing still requires FFmpeg on both peers; audio is not included.
