# CaeDuex v1.3

普通投屏保留应用窗口和桌面捕获、多屏、曲面、世界固定与视角跟随、鼠标键盘交互、共享投屏和环境光。保留原生分辨率、原生帧率以及捕获和传输性能改进。

本版同时包含近期的面板快捷键、建筑预览与教程、音乐界面和兼容性修复。

选择与 Minecraft 版本及加载器匹配的 `caeduex-v1.3-<loader>-mc<version>.jar`，替换原实例中的旧 JAR；不要同时安装多个版本。现有普通投屏配置可继续使用。

提供 10 个 Fabric、6 个 Forge 和 4 个 NeoForge 安装包，以及 SHA-256 校验清单。版本列表和 Java 要求见项目兼容性说明。

Ordinary app casting retains window and desktop capture, multiple screens, curved surfaces, world and view anchors, mouse and keyboard interaction, sharing, ambient lighting, and native resolution and frame rate options. This release also includes recent panel, building preview/tutorial, music UI, and compatibility fixes. Install exactly one JAR matching your Minecraft version and loader.
