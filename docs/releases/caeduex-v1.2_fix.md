# CaeDuex v1.2_fix

The CaeDuex handwritten intro, HUD, control panel, and mod list use the new project name. The control panel links to the [CaeDuex repository](https://github.com/Mellivyne/CaeDuex).

Install the `caeduex-v1.2_fix` JAR for your Minecraft version and loader. Replace the previous JAR in the same instance to keep using your existing settings. The release directory includes SHA-256 checksums for all Fabric, Forge, and NeoForge builds.
