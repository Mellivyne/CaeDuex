# v1.2_fix publication review

This review covers the source and twelve exact-version artifacts selected for the corrective release. Source and extracted packaged content are scanned for credential patterns, personal mailbox data, local Windows user paths, private keys and complete live sharing invitations. Runtime profiles, account settings, local worlds, logs and private test launch helpers are excluded.

Regression fixtures remain source-only. The runtime JAR checks require the shared clipping guard and source/60/120 sharing controls, and reject packaged local runtime fixtures, certificate/key files and private configuration directories. Each release asset is checked against its local SHA-256 value after upload.

The release uses a new commit and the separate v1.2_fix tag. Historical commits, tags, release descriptions and existing release assets are retained. New commit and tag metadata use a GitHub no-reply identity.

Automated privacy scans do not prove the absence of security vulnerabilities or audit externally hosted videos and attachments. Shared invitations created during actual use remain private viewing credentials.
