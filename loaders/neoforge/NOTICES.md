# NeoForge compatibility

CaeDuex uses NeoForge and ModDevGradle to compile against Minecraft.
Minecraft and NeoForge are supplied by the launcher and are not bundled.
The mod includes the ZXing QR encoder. The Minecraft 26.3 build additionally
includes LWJGL TinyFD for local file selection. See `THIRD_PARTY_NOTICES.md`
for the bundled dependencies.
